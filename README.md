A program that writes one original one-line joke about working beside an AI
coding agent — the kind of demo-day disaster every developer recognises —
to `/output/entry.txt`.

Entry for the [make.fun bounty](https://make.fun/bounty/the-joke-about-the-demo-20261121-0551).
Referral: https://make.fun/r/m4psg5rh

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Deterministic: the same joke, byte for byte, on every run. No network, no
randomness, no clock.
